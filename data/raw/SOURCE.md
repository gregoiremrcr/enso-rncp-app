- Page de référence : https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso/roni/
- Version : ERSSTv6 (confirmée sur la page CPC consultée le 16 novembre 2026).
- Date d'extraction : 11 novembre 2026.
- Période présente dans le fichier : DJF 1950 à ASO 2026.
- SHA-256 du fichier : `1297887f581b6190e459cbbf8bdec9a703ff65c1a229e2de4dd94285254f35c8`.
